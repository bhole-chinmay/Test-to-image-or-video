# PromptFrame

A Next.js studio for text-to-image and text-to-video generation.

## Run locally

1. Copy `.env.example` to `.env.local` and set `POLLINATIONS_API_KEY`.
2. Install dependencies with `npm install`.
3. Start the app with `npm run dev`.

See [DEPLOYMENT.md](DEPLOYMENT.md) for deployment and server-side key setup.
